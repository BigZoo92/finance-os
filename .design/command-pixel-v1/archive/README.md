# Archive Policy

Historical visual research is intentionally omitted from this engineering handoff.

The original design process included:

- inspiration images
- Stitch experiments
- alternate navbar directions
- rejected Cockpit variations
- rejected colorways

These are useful design history but are dangerous implementation references because they can conflict with Command Pixel V1 FINAL.

The canonical Claude Design source still contains a clearly marked `99 ARCHIVE` area. Frames in that area must not be implemented unless explicitly requested for historical comparison.

If the raw historical export is retained elsewhere in the repository, keep it outside the canonical handoff path and label it clearly as non production reference.
